# 아파트 관리비 웹앱 요구사항 정의서

> 상태: **작성 중** (대화로 요구사항을 정리하는 단계)
> 최종 수정: 2026-11-14
> 표기: ✅ 확정 · ❓ 미정/확인 필요

---

## 1. 개요

- 아파트 관리비를 매달 입력하고 저장해 세대별 고지서로 인쇄하는 웹 애플리케이션.
- 현재 업무 방식: **엑셀 또는 수기** 작성 → 이 앱으로 대체하는 것이 목표.
- 주 사용자가 시니어(아버님)이므로 큰 글씨, 고대비, 키보드 중심 입력을 기본으로 한다. (`CLAUDE.md` 4항)

## 부록 A. 기존 코드에 미치는 영향 (아직 적용하지 않음)

요구사항이 확정되면 아래 내용을 반영해야 합니다. **현재는 기록만 해 둡니다.**

- **권한(U-4 ~ U-9)**
  - 계정 3개는 Firebase 콘솔에서 직접 만들고, 앱에는 회원가입 화면을 두지 않습니다. Firebase 설정에서도 이메일 가입을 막아야 합니다.
  - 계정별 **역할(관리자 / 관리소장)**을 저장할 곳이 필요합니다. (Custom Claims 또는 Firestore `users/{uid}` 문서)
  - 권한 제한은 화면에서 버튼을 숨기는 것만으로는 부족합니다. **Firestore 보안 규칙**으로 관리소장의 이전 달 수정, 결산된 달 수정(D-6) 등을 막아야 합니다.
  - 월별 단일 문서(D-1) 구조에서는 문서 일부 필드만 쓰도록 보안 규칙을 만들기가 까다롭습니다. 특히 U-10은 **세대별 "납부 완료" 상태에 따라 그 세대 납부 필드만 잠그는** 규칙이라, 단일 문서 구조로는 보안 규칙만으로 강제하기 어렵습니다. 문서 구조(세대별 납부를 하위 컬렉션으로 분리 등)를 다시 검토해야 합니다.
