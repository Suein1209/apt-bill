# 아파트 관리비 웹앱 요구사항 정의서

> 상태: **작성 중** (대화로 요구사항을 정리하는 단계)
> 최종 수정: 2026-11-11
> 표기: ✅ 확정 · ❓ 미정/확인 필요

---

## 1. 개요

- 아파트 관리비를 매달 입력하고 저장해 세대별 고지서로 인쇄하는 웹 애플리케이션.
- 현재 업무 방식: **엑셀 또는 수기** 작성 → 이 앱으로 대체하는 것이 목표.
- 주 사용자가 시니어(아버님)이므로 큰 글씨, 고대비, 키보드 중심 입력을 기본으로 한다. (`CLAUDE.md` 4항)

## 3. 세대(부과 단위) 구성

### 3.1 건물 구조

| ID | 요구사항 | 상태 |
|---|---|---|
| H-1 | 총 **9개 동**이다. | ✅ |
| H-2 | 각 동에 기본 **16세대**가 있다. | ✅ |
| H-3 | **1층**은 상가 자리다. **2층 이상**은 일반 주거 세대다. | ✅ |
| H-4 | 1층에는 **관리사무소**도 있다. | ✅ |

> ❓ **확인 필요**
> - 동마다 16세대면 총 9 × 16 = **144세대**이고, `CLAUDE.md`에는 "100세대 규모"로 적혀 있습니다. 실제 총 세대 수와 부과 건수를 확인해야 합니다.
> - 층수와 층당 호 수 (예: 4층 × 층당 4호)
> - 동 번호 체계 (예: 101~109동, 1~9동, 가/나/다동)
> - 호수 표기 (예: 101호, 102호 … 401호)
> - 동마다 구조가 같은지, 동별로 세대 수가 다른 곳이 있는지

### 3.2 부과 단위 (세대 ≠ 고지서 1장)

| ID | 요구사항 | 상태 |
|---|---|---|
| H-5 | 관리비는 **호 단위가 아니라 "부과 단위" 단위**로 매긴다. | ✅ |
| H-6 | 1층 상가는 **한 호에 가게 2개**가 들어가 있을 수 있다. 이 경우 **관리비 2건(고지서 2장)**이 나간다. | ✅ |
| H-7 | 한 호에 들어갈 수 있는 부과 단위의 최대 수 (2개가 최대인지) | ❓ |
| H-8 | 상가 입점이나 퇴점으로 한 호의 부과 단위가 바뀌는 경우, **화면에서 직접 추가하거나 삭제**할 수 있어야 하는지 | ❓ |
| H-9 | 관리사무소에도 관리비를 부과하는지 (부과 대상인지, 표시만 하는지) | ❓ |
| H-10 | 공실 세대 처리 (부과 제외, 0원, 공용비 분배 대상 포함 여부) | ❓ |

### 3.3 표시 이름

| ID | 요구사항 | 상태 |
|---|---|---|
| H-11 | **2층 이상** 주거 세대는 **동과 호수만** 표시한다. (예: `101동 201호`) | ✅ |
| H-12 | **1층** 부과 단위는 동·호수에 더해 **별칭**을 표시할 수 있다. (예: 상호명, `관리사무소`) | ✅ |
| H-13 | 세대주 이름이나 면적 같은 다른 정보는 고지서에 **표시하지 않는다**. | ✅ |
| H-14 | 1층 별칭이 표시되는 정확한 형식 (예: `101동 101호 (OO식당)`, 별칭만 표시) | ❓ |
| H-15 | 같은 호에 가게가 2개일 때 둘을 구분하는 표기 (예: `101-A`/`101-B`, 별칭으로만 구분) | ❓ |

## 5. 금액 입력 및 자동 분배

| ID | 요구사항 | 상태 |
|---|---|---|
| C-1 | 사용자는 **공용 비용 총액**과 **세대별 검침값** 등 원천 값을 입력한다. | ✅ |
| C-2 | 시스템은 입력값을 바탕으로 **부과 단위별 금액을 자동 계산하고 분배**한다. | ✅ |
| C-3 | 공용 비용의 분배 기준 (균등 분할, 면적 비례, 상가와 주거의 비율 차등 등). 항목마다 다를 수 있다. | ❓ |
| C-4 | 검침 항목의 계산 방식 (전월·당월 지침을 입력해 사용량을 계산하는지, 사용량을 바로 입력하는지 / 단가 × 사용량인지, 총액을 사용량 비율로 나누는지) | ❓ |
| C-5 | 나눠 떨어지지 않는 금액의 **원 단위 처리** (반올림, 절사, 10원 단위 처리, 남는 금액을 어느 세대에 넣을지) | ❓ |
| C-6 | 자동 계산된 금액을 세대별로 **직접 수정**할 수 있어야 하는지 | ❓ |
| C-7 | 관리사무소와 공실이 분배 대상에 들어가는지 (H-9, H-10과 연동) | ❓ |
| C-8 | 전월 미납액이나 연체료를 이월하는지 | ❓ |

> 위 항목들은 엑셀 양식을 받은 뒤 그 안의 수식을 기준으로 정리합니다.

## 부록 A. 기존 코드에 미치는 영향 (아직 적용하지 않음)

요구사항이 확정되면 아래 내용을 반영해야 합니다. **현재는 기록만 해 둡니다.**

- `src/types/bill.ts`
  - `HouseholdId`가 `${dong}-${ho}` 형식이라 **한 호에 가게 2개**인 경우(H-6)를 표현할 수 없습니다. 부과 단위 ID 체계를 다시 정해야 합니다.
  - `Household`에 1층 **별칭** 필드가 필요합니다. (H-12)
  - 공용 비용 총액과 검침값 같은 **원천 입력값**, 그리고 **분배 규칙**을 담을 타입이 필요합니다. (C-1 ~ C-4)
- `src/constants/feeItems.ts`: 확정된 항목 목록으로 교체해야 합니다. (F-1)
- `CLAUDE.md`: "100세대 규모" 표현을 실제 세대 수에 맞춰 고쳐야 합니다. (H-2)
