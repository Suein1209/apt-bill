## 3. 시나리오

각 시나리오는 **조건 → 할 일 → 기대 결과** 순서다.

### 로그인·권한 (A)

- **T-A1 등록된 계정 로그인**: 관리자 계정으로 로그인 → 홈 상단에 이름·역할이 보이고 "새 달 시작", "결산 완료" 버튼이 보인다. 관리소장으로 로그인하면 두 버튼이 없다.
- **T-A2 등록되지 않은 계정**: Firebase에 계정은 있지만 역할이 없는 계정으로 로그인 → 등록되지 않은 계정이라는 안내가 나오고 자료가 보이지 않는다.

### 월 홈·새 달·결산 (M)

- **T-M1 첫 달 시작**: 월 문서가 하나도 없는 상태(에뮬레이터)에서 관리자로 로그인 → 첫 달 시작 화면이 나오고, 시작하면 추가 공통 비용 항목이 기본 목록으로, 기본 공통 비용은 0원으로 시작한다.
- **T-M2 새 달 이어받기** (H-25, F-16, D-4, D-7): 지난달에 공실 체크·기본/추가 공통 비용·안내문을 입력해 둠 → 관리자가 마지막 달에서 "새 달 시작" → 새 달에 공실 체크, 기본·추가 공통 비용 금액, 안내문이 그대로 있다. "지난달 수도 사용량·요금도 복사하기"를 체크했을 때만 수도 값이 복사된다.
- **T-M3 새 달 시작 시 지난달 자동 결산** (D-6): 마지막 달이 결산 전이고 미납 세대가 있음 → "새 달 시작"을 누르면 확인 창에 "○○년 ○월은 지금 미납액으로 함께 결산 완료됩니다."가 빨간 글씨로 보인다 → "시작하기" → 새 달로 이동하고, 지난달로 돌아가면 "결산 완료" 상태이며 수정할 수 없다. 새 달의 이월 미납이 지난달 결산 시점 미납액과 같다.
- **T-M4 지난달이 이미 결산된 경우**: 마지막 달을 먼저 "결산 완료" → "새 달 시작" → 확인 창에 자동 결산 문구가 없고, 지난달 결산 기록(결산 시각·미납액)이 바뀌지 않는다.
- **T-M5 결산·결산 취소** (D-6, D-8): 관리자가 "결산 완료" → 그 달이 읽기 전용이 되고 상단 배지가 결산 완료로 바뀐다. "결산 취소" → 다시 수정할 수 있고, 이월 미납이 실시간 계산으로 돌아간다.
- **T-M6 지난 달 접근 제한** (U-10, U-15): 관리소장으로 지난 달을 연다 → 보기만 되고 수정 칸이 비활성이다. 관리자는 결산 전인 지난 달을 수정할 수 있다.

### 비용 입력 (C)

- **T-C1 비용 입력과 합계**: "이번 달 비용 입력"에서 (나누는 세대 수 표시는 T-H1) 기본 공통 비용 4칸과 추가 공통 비용 항목 입력 → 각 구역 제목 아래 합계와 홈의 "세대당" 금액이 바로 바뀐다. 추가 공통 비용 카테고리·항목 추가·삭제·이름 변경이 저장된다.

### 동별 입력 Grid (G)

- **T-G1 키보드 연속 입력**: 동 버튼 → 첫 칸에서 숫자 입력 후 Enter·↑↓←→만으로 이동 → 비활성 칸은 건너뛰고, 마지막 칸에서 Enter를 눌러도 저장된다. 납부 상태 버튼에서는 Enter·스페이스로 미납/완납이 바뀐다.
- **T-G2 공실** (G-21, G-22): 관리자가 세대를 공실로 체크 → 그 세대는 공통 비용 분배에서 빠지고 다른 세대 몫이 다시 계산된다. 관리소장 화면에서는 공실 칸이 비활성이다. 관리자도 납부 확인된 세대의 공실은 바꿀 수 없다.
- **T-G3 수도 한쪽만 입력**: "수도 사용량(리터)"만 입력하고 요금은 비움 → 요금 칸이 0이 아니라 빈칸으로 보이고, 청구액 계산에서는 0원으로 친다.
- **T-G4 보기 전용 칸** (G-17, G-19): 이번 달 관리비와 납부일은 입력 칸이 아니라 값만 보인다. 납부 금액 칸과 "채우기" 버튼은 없다.
- **T-G5 납부 상태 토글** (G-20): "납부 상태" 칸에 미납 세대는 연한 주황 "미납", 낸 세대는 연두색 "완납" 버튼이 보인다. 관리소장이 "미납"을 누름 → "완납"으로 바뀌고 청구액 전액이 낸 것으로 저장되며, 납부일 칸에 `2026-11-15 12:30`(24시간제)과 다음 줄에 `관리소장`이 다른 칸보다 조금 작은 글씨로 보인다. 관리자가 누르면 `관리자`로 보인다. "완납"을 다시 누름 → "미납"으로 돌아가고 납부일 칸이 빈다. 청구액도 낸 금액도 없는 세대는 버튼이 없다. 관리자 화면에서 완납 세대만 "납부 확인" 가능하고 녹색 테두리가 보인다.
- **T-G6 납부 확인 세대 잠금** (G-18, G-20, G-22): 관리자가 "납부 확인"을 체크한 세대는 관리자·관리소장 모두 수도 사용량·요금, 공실, 납부 상태 버튼을 바꿀 수 없다(버튼이 흐리게 보이고 눌리지 않음). 관리자가 납부 확인을 풀면 다시 바꿀 수 있다.
- **T-G8 예전 납부 자료**: 이번 변경 전에 저장된 완납 세대 → 납부일 칸에 날짜만 보이고 시각·계정 줄은 없다. 일부만 낸 세대는 "미납"으로 보이고, 누르면 청구액 전액으로 완납 처리된다.
- **T-G7 관리실** (H-26): 6동 112호 관리실은 이름만 보이고 입력·납부 칸이 없다. 관리비를 나누지도 내지도 않아 세대당 금액 계산, 동 버튼 세대 수, 완납 판정, 출력 합계에서 모두 빠진다.
- **T-G9 오리집 2세대 몫** (H-22): 세대당 금액이 1,000원이면 오리집 청구액은 2,000원이고, 세대 이름 아래 "2세대분 합계"가 보인다. 5동 화면에서 오리집을 "완납"으로 바꿈 → 6동 화면에서도 "완납"과 같은 납부일·계정이 보인다. 관리자가 5동에서 "납부 확인"을 체크 → 6동에서도 체크돼 있고, 5동·6동 동 버튼 미납 수가 함께 1씩 줄어든다.

### 홈 동 버튼·세대 구성 (H)

- **T-H1 세대 구성**: 부과 단위 129곳 중 관리실을 빼고 오리집을 2세대로 세어 나누는 세대 129세대. 비용 화면에 "나누는 세대 (오리집 2세대, 관리실 제외) 129세대"로 보인다. 4층이 없고, 1층 107호는 "혜선집", 111호-1은 "유리", 5·6동은 "오리집"으로 묶여 보인다.
- **T-H2 완납 배지** (G-16): 한 동의 모든 부과 대상을 납부 확인 → 그 동 버튼 왼쪽 위에 "✓ 완납"과 "N세대 모두 납부 완료"가 보인다. 부과 대상이 없는 동에는 배지가 없다.

### 임시저장 (D)

- **T-D1 새로고침 복구**: 동별 입력이나 비용 입력에서 값을 입력하고 저장 전에 새로고침 → 복구 안내가 나오고 "다시 저장"·"버리기"를 고를 수 있다.
- **T-D2 복구가 다른 칸을 덮지 않음**: 다른 기기에서 같은 세대의 다른 칸을 저장한 뒤 복구 → 복구한 칸만 바뀌고 다른 칸은 유지된다. 권한이 없는 달이면 "이 달은 수정할 수 없습니다."가 나오고 임시저장이 지워진다.

### 출력 (P)

- **T-P1 납부표 출력** (P-14~P-17): 홈 맨 아래 "출력" → "납부 확인표"와 "납부 금액표" 중 선택 → A4 가로 미리보기가 9동부터 1동 순서로, 층별·동별 합계와 함께 보인다. "인쇄하기"로 OS 인쇄 창이 열리고 PDF로 저장할 수 있다.
